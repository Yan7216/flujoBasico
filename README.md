# ¿Qué es una Base de Datos Relacional?

Es una colección de información organizada en tablas con datos que se relacionan entre sí,se basa en el modelo relacional,que permite estructurar los datos de manera que se evite la duplicidad y se garantice la integridad de la información.


# ¿Qué es una Tabla en el contexto Base De Datos Relacionales?

Es la unidad básica de almacenamiento,es como una hoja de cálculo de excel, una estructura de filas y columnas donde guardas datos sobre un tema específico para que sea ordenado y no un caos completo


# ¿Qué es una relación en el contexto de Base De Datos Relacionales?

Es el vinculo que existe entre 2 tablas es para que se relacionen como el cliente y sus pedidos sirve para ubicar de forma ordenada cada dato insertado
